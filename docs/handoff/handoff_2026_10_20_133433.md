## 1. State in one paragraph

k8s-RemValGate is a group project for the course Language Models and Agents (CL3410): a small
fine-tuned validity gate that scores candidate fixes proposed by an LLM planner for Kubernetes
incidents, applies the best one only above a calibrated threshold, and otherwise escalates to a human.
It is evaluated on AIOpsLab mitigation problems against seven baselines. The project is in planning:
the requirements document (`docs/brd.md`, version 1.2), a README and a `.gitignore` are on `main`,
and the work is tracked as 68 issues (10 epics, 58 stories) on a GitHub Project. There is no
runnable code yet. Four decision issues wait for the group. Course milestones: mid-submission
2026-10-30, final submission 2026-11-15 (no extension), evaluations 2026-11-16 to 2026-11-19.

## 6. Preferences that bind the work

- Neutral, concise, no walls of text, no em dash, en dash or double dash outside code, no emojis.
- No tokens, passwords or private links in any file. Large artifacts (weights, rollout logs, datasets)
  stay on shared drive storage, referenced by checksum, never committed.
- No attribution or co-author trailers, and no references to tooling or to anything outside this
  repository, in files, commits, pull requests or comments.
- Commit scope: one logical change with its related tests and docs, corrections folded in before the
  first push, one commit per review round, usually 3 to 8 commits per pull request. Stage explicit file
  lists. Push only on an explicit yes. Pull requests are draft until the author marks them ready.
- Never tune prompts or judges on the sealed confirmation slice. Every use of the pool or the slice is
  logged. Every reported result carries a run manifest with model name, version and date.
- Assignees stay blank until the group agrees who does what. Never record a choice as the group's unless
  it is.

## 7. Tools

- `gh` with `project` scope. Sub-issues: `POST /repos/{owner}/{repo}/issues/{n}/sub_issues` with the
  child's database id (not its number). Blocked-by: `POST .../dependencies/blocked_by` with
  `issue_id` (database id). Pace calls to avoid secondary rate limits.
- GitHub Project fields are changed with GraphQL; `updateProjectV2Field` replaces all options. The
  Project's item listing can lag several minutes after bulk adds; check items per issue instead.
- GitHub Actions on a free private repository: 2,000 minutes a month, billed to the repository owner.
- Planned stack: Python with a lockfile and a plain `requirements.txt` export for Colab, a kind
  cluster running AIOpsLab (pinned commit), Qwen3.5-4B with LoRA, a cross-encoder reranker.
